# Matrix Operations in C

## About the Project
This project is developed as part of the CodeAlpha Internship. It is a C program that performs different matrix operations using two-dimensional arrays.

## Features
- **Matrix Transpose:** Converts rows into columns and columns into rows.
- **Matrix Addition:** Adds two matrices of compatible dimensions.
- **Matrix Multiplication:** Multiplies two matrices when their dimensions are compatible.

## Technologies Used
- C Programming
- GCC Compiler

## Concepts Used
- Two-dimensional arrays
- Nested loops
- Conditional statements
- Matrix operations
- User input and output

## How to Run

1. Download or clone this repository.
2. Open the project folder in the terminal.
3. Compile the program:

```bash
gcc matrix.c -o matrix
```

4. Run the program:

```bash
./matrix
```
